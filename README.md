# Major and Refractory Elements Periodic Table

An interactive geological reference for major and refractory elements, with fusion, XRF, ICP-OES, and ICP-MS method context, element details, filters, and image export.

## Run locally

Open [`index.html`](index.html) in a modern browser. The project is a self-contained HTML page with no build step or external JavaScript dependencies.

## GitHub Pages

To host the page, open **Settings > Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

## Disclaimer

This is an informational reference, not a validated laboratory procedure. Confirm method suitability, detection limits, and operating conditions against applicable standards and validated laboratory procedures.
